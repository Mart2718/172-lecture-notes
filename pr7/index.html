Definition: rational function

From the handout

A function r is rational provided that it is possible to write r as the ratio of two polynomials, p and q. That is, r is rational provided that for some polynomial functions p and q, we have r(x) = p(x)/(q(x)).

Note: goals for this lesson

From the handout

Rational functions occur in many applications, so our goal in this lesson is to learn about their properties and be able to graph them. In particular we want to investigate the domain, end behavior, and zeros of rational functions.

Activity 1 · from your notes

Consider the rational function r(x) = (x² − 3x + 2)/(x² − 4x + 3).

(a) Find r(1), r(2), r(3), and r(4).

Hint for Activity 1(a)

Hint: Substitute each value into the top and the bottom separately.

Show answer to Activity 1(a)

Answer (a)

r(1) = (1 − 3 + 2)/(1 − 4 + 3) = 0/0 → undefined

r(2) = (4 − 6 + 2)/(4 − 8 + 3) = 0/(−1) = 0

r(3) = (9 − 9 + 2)/(9 − 12 + 3) = 2/0 → undefined

r(4) = (16 − 12 + 2)/(16 − 16 + 3) = 6/3 = 2

Final answer: r(1) and r(3) are undefined; r(2) = 0; r(4) = 2

(b) Label each of these four values as giving us information about the DOMAIN of r(x), information about the ZEROES of r(x), or NEITHER.

Hint for Activity 1(b)

Hint: Undefined tells you about the domain. A value of 0 tells you about zeros.

Show answer to Activity 1(b)

Answer (b)

  • r(1), r(3): domain. The denominator is 0, so 1 and 3 are not in the domain.
  • r(2) = 0: zero. The graph crosses or touches the x-axis at x = 2.
  • r(4) = 2: neither. It's just a point on the graph, (4, 2).

Final answer: r(1), r(3): domain · r(2): zero · r(4): neither

⚠ Watch out: r(1) is 0 over 0, not 0. A zero needs the numerator to be 0 while the denominator is not.

Note: domain of a rational function

From the handout

Let p and q be polynomial functions so that r(x) = p(x)/(q(x)) is a rational function. The domain of r is the set of all real numbers except those for which q(x) = 0.

Note: zeros, asymptotes, and holes

From the handout

Let r(x) = p(x)/(q(x)) be a rational function.

  • If p(a) = 0 and q(a) ≠ 0, then r(a) = 0, so r has a zero at x = a.
  • If q(a) = 0 and p(a) ≠ 0, then r(a) is undefined and r has a vertical asymptote at x = a.
  • If p(a) = 0 and q(a) = 0 and we can show that there is a finite number L such that r(x) → approaches L as x → approaches a, then r(a) is not defined and r has a hole at the point (a, L).

Note: end behavior

From the handout

Another property of rational functions we want to explore is the end behavior. This means we want to explore what happens to a given rational function r(x) when x goes toward positive infinity or negative infinity.

Show answer to Activity 3(b)

Answer (b)

Final answer: as x → approaches −∞, r(x) → approaches 0

The values are tiny negative numbers. They get close to 0 from below, but they still approach 0.

Note: 1 over x to the n

From the handout

We can generalize what we have just found to any function of the form 1/(xⁿ), where n > 0. Since xⁿ increases without bound as x → approaches ∞, we find that 1/(xⁿ) will tend to 0. In fact, the numerator can be any constant and the function will still tend to 0!

Similarly, as x → approaches −∞, we find that 1/(xⁿ) will tend to 0 too.

Note: horizontal asymptote

From the handout

If the end behavior of a function tends toward a specific value a, then we say that the function has a horizontal asymptote at y = a.

(a) Find the horizontal asymptote of f(x) = (4x³ − 3x² + 6)/(9x³ + 7x − 5).

Activity 8 · from your notes

Let f(x) = (−(x − 1)(x − 4))/(2(x + 3)²(x − 1)).

(a) Find the roots of f(x).

Hint for Activity 8(a)

Hint: Which numerator zeros are also denominator zeros?

Show answer to Activity 8(a)

Answer (a)

The numerator is zero at x = 1 and x = 4. But x = 1 also makes the denominator zero, so it is not a root.

Final answer: x = 4

⚠ Watch out: x = 1 cancels from top and bottom. That's a hole, not a root.

(b) Find the y-intercept of the graph of f(x).

Show answer to Activity 8(b)

Answer (b)

f(0) = −(−1)(−4)/(2(3)²(−1)) = −4/(−18) = 2/9

Final answer: (0, 2/9)

(c) Find any horizontal asymptotes on the graph of f(x).

Show answer to Activity 8(c)

Answer (c)

Numerator degree 2, denominator degree 1 + 2 = 3. The bottom wins.

Final answer: y = 0

(d) Find any vertical asymptotes on the graph of f(x).

Show answer to Activity 8(d)

Answer (d)

After canceling (x − 1), only (x + 3)² is left in the denominator.

Final answer: x = −3

(e) Find any holes on the graph of f(x).

Hint for Activity 8(e)

Hint: Use the canceled form to find the y-value of the hole.

Show answer to Activity 8(e)

Answer (e)

Cancel (x − 1): f(x) = (−(x − 4))/(2(x + 3)²) for x ≠ 1. Plug in x = 1: (−(1 − 4))/(2(4)²) = 3/32.

Final answer: Hole at (1, 3/32)

(f) Sketch the graph of f(x).

Show answer to Activity 8(f)

Answer (f)

Put it together: x-intercept 4, y-intercept 2/9, hole at (1, 3/32), vertical asymptote x = −3 (squared factor, so the graph goes up on both sides), horizontal asymptote y = 0.

Final answer: See the sketch

Near x = −3, the (x + 3)² in the bottom is always positive and the top is positive, so both sides go to +∞.

Suppose you are given a function r(x) = p(x)/(q(x)), and you know that p(3) = 0 and q(3) = 0. What can you conclude about the function r(x) at x = 3?

(a) What can you conclude?

Hint for Activity 10(a)

Show answer to Activity 10(a)

Answer (a)

r(3) is undefined. Beyond that, it depends on how many factors of (x − 3) are on top and on bottom:

  • (x − 3)/(x − 3): everything cancels → a hole at x = 3.

Graphing checklist: steps for graphing a rational function

✎ Extra note: not in your handout

  1. Factor the top and bottom completely.
  2. Excluded values: list every zero of the original denominator.
  3. Hole or asymptote? Cancel common factors completely. At each excluded value: if the simplified denominator is no longer zero, it's a hole (find its y-value from the simplified form); if the simplified denominator is still zero, it's a vertical asymptote. (Example: in (x − 3)/(x − 3)², one factor cancels but x = 3 is still an asymptote, as in Activity 10.)
  4. x-intercepts: zeros of the simplified numerator that are in the original domain. y-intercept: r(0), if 0 is in the domain.
  5. Horizontal asymptote: compare degrees (Activity 6).
  6. Sketch, using a test point in each region to see whether the graph is above or below the axis.
